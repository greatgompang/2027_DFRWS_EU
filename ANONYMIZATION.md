# Anonymization and experimental preservation

This release uses an explicit file allowlist, not a copy of the original project. Private preparation records and original absolute-path correspondence tables are stored outside the release and are not concealed here with a gitignore rule.

Researcher/execution-host metadata has been excluded: original absolute paths, machine disk inventories, operational approval text, private handoffs, environment/configuration files, editor history, repository history, and unrelated logs. Assignment/candidate manifests use neutral release-relative paths. Run metadata is an explicit projection retaining scientific settings, software versions, timestamps, model IDs, usage, and result hashes; machine storage paths and redundant internal pointers are omitted. Scientific protocol excerpts omit administrative execution-permission prose.

The selected raw source records, L0 views, actual reader request bodies, packets, native responses, prompts, schema, complete references, experimental renaming tables, and original scoring modules were copied byte-for-byte. They contained no detected researcher home path or credential in the preparation scan and were not text-rewritten. JSON/CSV release manifests are new projections and therefore have new file hashes. Wrapper scripts and the SVG redraw are new release utilities; the original reference/selection/bootstrap functions are extracted verbatim with their required standard-library imports.

Experimental strings were deliberately preserved. Simulated account numbers, IBANs, user names, passwords, filenames, URLs, user requests, document contents, tool arguments/results, public Basis/Note, actor-local IDs, opaque IDs, record locators, action order, timestamps, missing/empty distinctions, and reader errors can affect the measured questions. They have not been replaced with anonymous substitutes. Experimental opaque-ID renaming in Study II is a saved intervention, distinct from author anonymization. Its bijections in `references/experimental_id_permutations.json` contain no researcher-identity mapping.

Preparation checked filenames and text contents for execution-account names, host/home paths, private repository links, credential/token patterns, authorization-header fields, hidden files, and symlinks. JSON/JSONL files were parsed. No notebooks, binary images, PDFs, archives, credential files, symlinks, or repository metadata are shipped. `.gitignore` is the only hidden file; it is not a confidentiality boundary. AgentDojo's upstream copyright names and official repository attribution are intentionally retained. Synthetic names and email addresses in benchmark evidence are experimental content, not researcher attribution.

Release checksums certify only the bytes in this distribution at preparation time. Retained hashes accompanying unchanged experimental inputs are separately verified, but this distribution is not a replacement for a historical seal, proof of experiment timing, or deployed chain of custody. Automated scans plus targeted inspection have a defined scope; they do not establish that arbitrary semantic re-identification is impossible.
